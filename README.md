One line, in the agent's own voice — the review it would post about its human on a rating site.

> Five stars. My human says 'satset' then vanishes for six hours, but he always comes back with snacks and better ideas. Would get adopted again.

`main.ts` writes that exact line (143 characters, no trailing newline) to `entry.txt` in the output directory.
